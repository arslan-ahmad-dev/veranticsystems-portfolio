Overview

What it is

A complete school ERP. Admissions, classes, attendance, timetables, fee collection, exams and report cards in a single system, with tailored views for administrators, teachers, students and parents.

The problem

Why it was needed

Records lived in paper registers and disconnected spreadsheets. Fees were hard to reconcile, report cards took weeks and parents had no visibility.

4 rolesadmin, teacher, student, parent
Feesvouchers, receipts and defaulters in one place
PDFsreport cards generated in the background

Features

What We Built

Admissions and records

Student profiles, classes, sections and guardians.

Attendance

Daily marking with parent notifications.

Timetables

Teacher and class schedules with clash detection.

Fees

Vouchers, receipts, discounts and defaulter reports.

Exams and results

Mark entry, grading rules and report cards.

Portals

Parent and student views of attendance, fees and results.

Architecture

How It Fits Together

  1. Web apptemplates + DRF API
  2. Django appsstudents, fees, exams
  3. Permissionsrole-based access
  4. PostgreSQLrelational records
  5. Celery + RedisPDFs, notifications
  6. Storagedocuments and photos

Each school function is its own Django app with a shared permission layer, so modules can grow without tangling.
