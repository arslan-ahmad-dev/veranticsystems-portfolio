Overview

What it is

A data-collection service for Walmart marketplace listings. It crawls chosen categories, keywords and sellers, cleans and de-duplicates the results and serves them through a private API and scheduled exports.

The problem

Why it was needed

The client needed catalogue and pricing data in a consistent shape, but raw page data was messy, changed often and arrived with duplicates across crawls.

Normalisedtyped, consistent fields across runs
De-duplicatedno repeats between crawls
API + CSVdata ready for BI or repricing

Features

What We Built

Targeted crawls

By category, keyword, seller or product list.

Normalisation

Consistent price, availability and attribute fields.

De-duplication

Stable product keys across runs.

Private API

FastAPI endpoints with filtering and pagination.

Scheduled exports

CSV drops to storage on a schedule.

Run reports

Coverage, failures and timing for every crawl.
